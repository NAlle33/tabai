# AGENTS.md

The agent instructions for this repository live in [CLAUDE.md](CLAUDE.md). Read that file in
full before making changes: it owns the commands, the build-and-reload loop, the non-derivable
constraints and the security invariants. This file exists only so tools that load `AGENTS.md`
(Codex and others) find the same instructions; it is a plain file rather than a symlink so it
survives checkouts on Windows.
